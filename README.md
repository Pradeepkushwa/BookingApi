# Fitness Studio Booking API

This is a simple booking system API for a fictional fitness studio, built using **Django** and **Django REST Framework (DRF)**. It allows clients to view upcoming classes, book a class, and view their bookings.

---

## 

- View all upcoming fitness classes
- Book a class by providing class ID, name, and email
- Check all bookings by email
- Logs all API activities and errors into a daily log file
- Timezone-aware scheduling (IST)
- Input validation and error handling

---

## 

- Python 3.x
- Django
- Django REST Framework
- SQLite (in-memory or file-based)
- Logging via Python’s logging module
